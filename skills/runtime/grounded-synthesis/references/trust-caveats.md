# Trust Tier Disclaimers and Caveats

Apply these mandatory caveats based on the protocol's declared trust tier:

- **Tier 1 (Authoritative Institutional Guideline):**
  "Validated against governing institutional laboratory medicine protocol."
- **Tier 2 (Peer-Reviewed Consensus):**
  "Reference range derived from peer-reviewed multi-center clinical consensus guidelines."
- **Tier 3 (Manufacturer Package Insert):**
  "Assay parameters reflect manufacturer package insert; verify with local laboratory standard operating procedure."
- **Tier 4 (Unverified / Staging):**
  "Caution: Protocol from staging source; clinical confirmation required."
