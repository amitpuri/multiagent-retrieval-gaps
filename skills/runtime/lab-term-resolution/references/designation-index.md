# Designation Index (Ambiguous Lab Designations)

This index lists common clinical lab designations that map to multiple distinct observables.

| Designation | Possible Canonical Observables | Differentiating Facets / Units |
| :--- | :--- | :--- |
| `Hb` | Blood Hemoglobin (loinc:718-7), Glycated Hemoglobin (loinc:4548-4) | mass concentration vs fraction |
| `Calcium` | Total Serum Calcium (loinc:17861-6), Ionized Calcium (loinc:1994-3) | total facet vs ionized facet |
| `Troponin` | Troponin I (loinc:10839-9), High-Sensitivity Troponin T (loinc:6598-7) | assay type, mass concentration unit |
| `CSF panel` | Lumbar Puncture Multi-Tube Emergency Workup | Tube sequence 1 to 3 |
