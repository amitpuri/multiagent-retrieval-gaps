# Panel Reference Directory

## Lumbar Puncture Emergency Panel (`panel:csf_emergency`)

- **Specimen:** Cerebrospinal Fluid (CSF)
- **Sequence:**
  1. **Tube 1:** Clinical Biochemistry (Protein, Glucose analysis).
  2. **Tube 2:** Clinical Microbiology (Gram stain, Culture, Meningitis PCR).
  3. **Tube 3:** Hematology (Cell count, Differential, rule out traumatic tap).
- **Rule:** Tube order strictly preserves specimen integrity to avoid cross-contamination.
